## NCCL facts

From `~/vllm-cache/nccl-<ALIAS_RANK0>-283.log` (NCCL 2.30.7+cuda13.0, the patched build):

- Transport: `NET/IB : Using [0]rocep1s0f0:1/RoCE [1]rocep1s0f1:1/RoCE [RO]`; 4 channels, all
  `via NET/IB/2`; rings `3 -> 0 -> 1` on all 4 channels; `Trees` degenerate
  (skip-tree-connect) — expected on the switchless ring.
- **`Connected all rings, use ring PXN 0 GDR 0`** and `Symmetric memory is not supported.
  cuMemEnable 0, globalGinSupport 0, cuMemGdrSupport 0`; `nvidia_peermem` is **not loaded** on
  the host. Consequence: every network message is staged through host bounce buffers — no
  GPUDirect today.
- TUNING histogram (boot + bench). AllReduce: 32 KB → RING/LL, channels {0..1} (1001×, the
  decode step size: 4 tokens × 4096 × bf16); 8/16 KB → LL 1 ch; 64/128 KB → LL 4 ch;
  196-647 KB → LL128 4 ch; 20-67 MB → SIMPLE 4 ch (prefill chunks, 8192 tok × 4096 × 2 B =
  64 MB); 303 MB → SIMPLE. AllGather 310 KB → LL128.
- The patched build exports `NCCL_NET_GDR_C2C`, `NCCL_NET_GDR_LEVEL`, `NCCL_DMABUF_ENABLE`,
  `NCCL_IB_MERGE_NICS`, `NCCL_BUFFSIZE`, `NCCL_NTHREADS`, `NCCL_IB_QPS_PER_CONNECTION`,
  `NCCL_IB_SPLIT_DATA_ON_QPS` — the knobs W4a will use.

## Reading

1. **Engine unchanged → every delta is noise or warm-up.** Prefill 30k +8.8% vs 09-02
   (2075 vs 1908) is explained by the discarded warm-up pass (JIT compile of the
   mhc/topk/indexer shapes lands in the first requests; the 09-02 pass had none), so
   **2075 / 2136 become the reference prefill numbers.** Prose 36.6-36.7 vs 35.6 (+3%, inside
   the ±5% band), structured 48.1 vs 50.2 (−4%, inside), c4 124/33.5 vs 127/33.6 (flat).
   Code 42.0 vs 35.5: the 09-02 number had a 22.8-39.1 spread, so **42 is the new reference**
   (E0 already read 41.3 this morning).
2. **@1400 at k=3 = 46.6 tok/s** (k=7 on 09-02: 59.6) — first measurement of sustained long
   structured decode at k=3. The width-capped acceptance costs **~22%** there, consistent
   with the 09-02 lane decision (prose first, structured pays).
3. **The collective ceiling is host-staged.** `GDR 0` and `cuMemGdrSupport 0` mean the decode
   AllReduce (32 KB, dominant at 1001 occurrences) crosses host bounce buffers on every step,
   and so do the prefill 20-67 MB SIMPLE chunks — the only measured ceiling datum from W1.
4. **The torch profiler is unavailable on this build.** `/start_profile` and `/stop_profile`
   return **404**: this image's `api_server.py` has no profiler routes (openapi lists only
   `/health` and `/metrics` among them), so `VLLM_TORCH_PROFILER_DIR` is set but unused.
   Per-kernel time shares remain unmeasured — the NCCL log is W1's only ceiling data.
5. **Campaign re-ordering.** W4a (`NCCL_NET_GDR_C2C=1 NCCL_NET_GDR_LEVEL=SYS
   NCCL_DMABUF_ENABLE=1`, overlay `experiments/2026-09-03-w4a-gdr-c2c.env`) is now
   evidence-backed by point 3 (GDR is off today) and **moves ahead of W2**
   (`experiments/2026-09-03-w2a-moe-triton.env`, `…-w2b-e8m0-off.env`).
6. **Harness lessons.** Always run and discard a warm-up pass after a boot, otherwise the
   first prefill is a JIT measurement. And always pass `--out` to manual `bench_decode.py`
   runs (or go through `run_ab.sh`), otherwise the numbers leave no JSON — as above.
